# Decisions

Each entry: decision, reason, consequence. Dates are 2026-10-23 unless noted.

1. **Stack: Next.js 16 (App Router, static export) + TypeScript + React 19.** Reason: server-rendered
   HTML with small client islands; static export gives a plain `out/` folder that any static host or
   `npx serve out` can run. Consequence: `images.unoptimized` (image derivatives are pre-built by
   `scripts/build_media.py`), `generateStaticParams` for project routes, no server runtime.
2. **3D: three.js + @react-three/fiber + @react-three/drei, procedural geometry.** Reason: no CAD or
   mesh sources exist in the archive; procedural fins and massing are smaller, cleaner and easier to
   maintain than hand-built GLBs and can be re-parameterised when originals arrive. Consequence: both
   models are labelled interpretive; assumptions recorded in docs/RECONSTRUCTION.md.
3. **Motion: `motion` (Motion One / Framer successor) for DOM; three.js owns camera/scene tweens.**
   No GSAP, no scroll smoothing. Reason: one engine per property set.
4. **Styling: Tailwind CSS 4 with a token layer in `src/app/globals.css` (`@theme`).** Radix primitives
   for dialog, slider, switch, tooltip, restyled.
5. **Fonts (self-hosted via Fontsource, OFL):** Newsreader (variable, optical sizes) for display and
   editorial text — a Scotch-roman like the serif on the portfolio pages; Hanken Grotesk (variable)
   for interface and body; IBM Plex Mono 400 only for drawing metadata (sheet, scale, source page).
   Instrument Serif + Manrope were evaluated and rejected: both are the current default pairing in
   generated sites and Instrument Serif's narrow display cut does not match the portfolio's own serif.
6. **Palette:** warm chalk `#F3F0E9` page, sheet white `#FBFAF7` for drawing surfaces, ink `#191A18`,
   secondary text `#5B574F` (passes AA on chalk), rule grey `#9A948B` (rules and surfaces only),
   burnt copper `#A95336` (Maison Peplum timber; single accent), red pencil `#B8322A` (Cairo only,
   sampled from the dissertation drawings). Contrast pairs are checked by `scripts/check_contrast.py`.
7. **Hero = Maison Peplum.** Validated: fin silhouette is the most distinctive form; the supplied
   renders (358–687 px) cannot carry a hero; the 1:200 model photos confirm the wave-profile fins.
8. **Sound Aroma Loom** is a text-led entry inside /work with a small, clearly labelled interpretive
   sensory diagram (SVG). No fabricated drawings.
9. **Cairo atlas is schematic.** Cases are arranged by spatial category, not geography. No map
   library, no coordinates. Figure 10 (third-party photo) is cited, not displayed.
10. **Research download:** a reading edition (dissertation pages 1–28, excluding appendices) is
    generated by `scripts/make_research_excerpt.py` and inspected; the full original is not published.
11. **Contact/CV:** none supplied. No contact buttons, no email, no CV link. Tracked in
    docs/CONTENT_NEEDED.md.
12. **Rendering lifecycle:** one `ModelViewer` shell owns canvas state (poster → loading →
    interactive → paused/fallback/error). Demand rendering at rest; frames scheduled explicitly while
    auto-rotate or a guided transition runs; user input cancels guided camera moves.
13. **URL state:** view preset and assembly value live in the URL hash (`#view=assembly&fold=0.6`),
    replaced without history entries.
